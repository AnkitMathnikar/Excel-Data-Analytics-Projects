# 📊 Excel Data Analytics Projects

A collection of **Microsoft Excel data analytics projects** demonstrating practical skills in data cleaning, data transformation, data analysis, data visualization, dashboard development, and business-oriented insights.

This repository represents my hands-on journey toward becoming a **Data Analyst**, starting with Excel fundamentals and progressing toward more advanced analytical workflows.

## 👨‍💻 About This Repository

This repository contains five Excel projects covering different real-world datasets and business scenarios.

Across these projects, I have worked with:

- Raw datasets
- Data cleaning and preparation
- Data transformation
- Excel formulas and functions
- PivotTables
- PivotCharts
- Interactive dashboards
- Slicers and filters
- Time-based analysis
- Product and category analysis
- Revenue and transaction analysis
- Business insights
- Power Query
- Power Pivot / Data Modeling
- Basic DAX where applicable

The goal of these projects is not only to create dashboards, but to demonstrate the complete process of turning raw data into meaningful and understandable business information.
