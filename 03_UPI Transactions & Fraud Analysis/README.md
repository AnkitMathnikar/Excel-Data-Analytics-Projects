## 📌 Project Overview

This project analyzes UPI transaction data using Microsoft Excel to understand transaction performance, payment behavior, customer activity, and transaction trends.

The project follows an end-to-end data analytics workflow, transforming raw transaction data into a structured dataset and an interactive dashboard that helps users explore transaction patterns and generate meaningful business insights.

---

## 🎯 Business Objective

The main objective of this project is to analyze UPI transaction data and answer important business questions such as:

- What is the overall transaction volume and transaction value?
- How do transaction amounts change over time?
- Which payment methods are used most frequently?
- Which transaction types contribute the most to transaction activity?
- What is the success and failure rate of transactions?
- Which locations generate the highest transaction activity?
- How does transaction behavior vary across different customer segments?
- Are there noticeable patterns or trends in transaction activity?
- What business insights can be derived from the transaction data?

---

## 📊 Dataset

The project uses a UPI transaction dataset containing transaction-level information related to digital payments.

The dataset includes relevant fields that can be used to analyze:

- Transaction ID
- Transaction amount
- Transaction date/time
- Transaction status
- Transaction type
- Payment method
- Customer information
- Location
- Other transaction-related attributes

The raw dataset was cleaned, transformed, and prepared for analysis using Excel.

## 🔄 Project Workflow

The project followed an end-to-end data analytics workflow:

**Raw Data → Data Cleaning → Data Transformation → Data Analysis → Dashboard → Business Insights**

### 1. Data Preparation

The raw UPI transaction data was imported into Excel and reviewed to understand the available fields and overall data structure.

The initial review focused on:

- Missing values
- Incorrect data types
- Duplicate records
- Inconsistent values
- Formatting issues
- Unnecessary columns
- Data quality issues

---

### 2. Data Cleaning & Transformation

Power Query was used to clean and transform the raw transaction data before analysis.

Key activities included:

- Cleaning raw transaction data
- Changing data types
- Removing unnecessary columns
- Standardizing values
- Handling missing or inconsistent data
- Transforming fields for analysis
- Preparing analysis-ready data

---

### 3. Data Analysis

The cleaned data was analyzed using Excel analytical tools such as PivotTables, PivotCharts, calculated columns, and measures where applicable.

The analysis focused on:

- Transaction volume
- Transaction value
- Transaction status
- Payment methods
- Transaction types
- Customer activity
- Geographic performance
- Time-based transaction trends

### Geographic Analysis
