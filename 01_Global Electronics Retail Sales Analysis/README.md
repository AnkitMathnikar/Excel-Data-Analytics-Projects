## 📌 Project Overview

This project analyzes sales data from a global electronics retailer using Microsoft Excel to uncover trends in sales performance, product categories, customer behavior, and geographic performance.

The project focuses on transforming raw business data into a structured analytical model and an interactive dashboard that can be used to explore sales performance and generate business insights.

---

## 🎯 Business Objective

The main objective of this project is to analyze retail sales data and answer important business questions such as:

- How are overall sales performing?
- Which products and categories generate the most revenue?
- Which countries or regions contribute the most to sales?
- How do sales change over time?
- Which products have stronger or weaker performance?
- Who are the major customers?
- What patterns can be identified from the sales data?
- Where are potential opportunities for improving sales performance?

---

## 📊 Dataset

The project uses the **Global Electronics Retailer** dataset from Maven Analytics.

The dataset contains information related to:

- Sales transactions
- Products
- Product categories
- Customers
- Stores
- Locations
- Dates

The different tables were transformed and organized to create a structured dataset suitable for analysis.

## 🔄 Project Workflow

The project followed an end-to-end data analytics workflow:

**Raw Data → Data Cleaning → Data Transformation → Data Modeling → Analysis → Dashboard → Business Insights**

### 1. Data Preparation

The raw datasets were imported into Excel and reviewed for:

- Missing values
- Incorrect data types
- Duplicate or inconsistent records
- Formatting issues
- Unnecessary columns
- Data quality problems

### 2. Data Cleaning & Transformation

Power Query was used to prepare the datasets for analysis.

Key activities included:

- Cleaning and transforming raw data
- Changing data types
- Removing unnecessary columns
- Standardizing data
- Combining relevant datasets
- Creating analysis-ready tables


### 3. Data Modeling

Power Pivot was used to organize the data into a structured analytical model.

Relationships between relevant tables were created to allow information from different datasets to be analyzed together.
